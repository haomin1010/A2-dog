# 阶段 1 测试运行手册（Runbook）

目标：在真机上验证"语音/文字 → 大模型 → 站/趴/走/跑/转/停/说/等"，并标定参数。

按顺序做，**每一步通过再进下一步**：

| 步骤 | 内容 | 狗的状态 |
|---|---|---|
| 1 | 开机前：服务器自测 | 关机 |
| 2 | 开机后：网络 + 只读自检 | 开机、趴着，**不会动** |
| 3 | 运动前安全检查 | 趴着 |
| 4 | 限速运动测试 | **会动** |
| 5 | 放开限速 + 语音测试 | **会动** |
| 6 | 收尾 | 趴下 |

附录：A 接线组网（线已接好时跳过）、B 故障排查、C 网络切换。

## 2. 开机后：网络 + 只读自检（狗不会动）

狗开机，**保持趴着**，等 1–2 分钟让 PC2 启动完成。

### 2.1 网络（服务器上）
```bash
ip -br addr show enxec1ac314450f     # 应看到 192.168.124.222/24 和 192.168.123.222/24
ping -c 3 192.168.124.162            # PC2 要通
```
网卡没 IP：`sudo nmcli con up unitree-a2`。仍不通 → 附录 A 检查接线。

### 2.2 只读自检（PC2 上）
```bash
ssh unitree@192.168.124.162
ping -c 3 192.168.123.161            # PC1（运控）要通
cd ~/lhm/A2-dog
tools/run_body.sh --check
```
**只读**：调用 GetState、读 `rt/sportmodestate`、读音量，不发任何运动指令。

| 输出 | 期望 | 不对时 |
|---|---|---|
| `GetState: {...'fsm_name': ...}` | 有字典，记录 fsm_name | code≠0 / 超时：PC1 不通或 DDS 网卡不对 |
| `rt/sportmodestate: {...}` | x/y/yaw/mode 有值，mode=1（STAND_DOWN） | `None`：里程计收不到，**先别进行运动测试** |
| `音量: (0, ...)` | 有返回 | 失败不影响运动，只是 speak 不可用 |

🛑 **把这段输出发给开发者确认后，再进行第 3 步。**

## 3. 运动前安全检查

- [ ] **场地**：狗周围 3 米内无人无障碍，前方至少 3 米直线空地。**狗没有避障**（自带 SLAM 处于待命），撞到东西不会自己停。
- [ ] **网线**：狗通过网线连着服务器，活动范围受网线长度限制。
  - 网线留足余量，**安排一个人专门理线、跟着狗走**；
  - 转圈用例注意别让线缠腿；
  - 网线被扯断/拔掉时，body 1 秒内收不到心跳会自动停下（有兜底，但别依赖）。
- [ ] **遥控器**：开机、已连上狗、**拿在一个专人手里**，这个人只负责急停。
- [ ] **电量** > 30%（遥控器或 App 查看）。
- [ ] 所有人知道急停方法（从快到慢）：

| 方法 | 效果 | 延迟 |
|---|---|---|
| 遥控器 | 宇树官方急停/接管 | 最快，最可靠 |
| brain 终端输入 `/stop` 回车 | 停止运动，原地站着 | 即时 |
| brain 终端 `Ctrl-C` | 连接断开 → body 立即 StopMove | 即时 |
| PC2 上 `Ctrl-C` 停 body | 退出前打断当前动作并 StopMove | 即时 |
| 说"停 / 别动 / 站住"（语音模式） | 跳过大模型直接停 | 说完 + 识别约 1s |
| 拔服务器↔狗的网线 | body 1 秒收不到心跳 → StopMove | ~1s |
| brain 终端 `/damp` | 电机阻尼，**狗会软倒**，最后手段 | 即时 |

## 附录 A：接线与组网（线已接好时跳过）

```
  你的电脑 ──SSH(跳板 jd_10002)──► 服务器 ──USB 千兆网卡──网线──► 狗的对外网口 ──► PC2 net1
                                     │                                         PC2 eth0 ──狗内网──► PC1
                                     └─ USB 麦克风（Newmine）
```

1. **麦克风**：USB 麦克风插服务器。
2. **网线**：服务器上的 USB 千兆网卡（ASIX AX88179，接口名 `enxec1ac314450f`）→ 网线 → 狗身上连 PC2 的千兆网口（PC2 侧是 `net1`，板载 Intel I219）。
   PC2 与 PC1 之间（`eth0`，123 网段）是狗内部连好的，不用管。
3. **服务器网卡 IP**：由 NetworkManager 连接 `unitree-a2` 自动配置（已开自动连接，插上即生效）。没生效时：`sudo nmcli con up unitree-a2`。
4. 检查方法见 2.1。

## 附录 B：故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| brain：`连不上 body 192.168.124.162:8765` | body 没启动 / 网络不通 | PC2 上看 body 是否在跑；`ping 192.168.124.162` |
| brain：`body 拒绝连接：口令错误` | 两端 `A2_TOKEN` 不一致 | 统一口令或都不设 |
| body 报 `GetState`/`StandUp 失败 code=...` | PC1 未响应、运控模式不对、遥控器占用 | 记下 code；检查遥控器模式；狗重启 |
| `Move 失败 code=...` | 狗还没进入可行走状态 | 记录；代码已自动 BalanceStand，仍失败则反馈 |
| `里程计中断` | `rt/sportmodestate` 停发 | 反馈 |
| `移动超时（只走了 x 米）` | 被挡住、速度达不到 | 检查场地；反馈实际速度 |
| 结果写"按时间估算" | 没收到里程计 | 距离会不准，反馈 |
| 一直"没听到说话" | 麦克风设备不对 / 太小声 | `arecord -l`，`--mic` 换设备 |
| `语音识别失败` / `大模型调用失败` | 外网或 key 问题 | `curl https://dashscope.aliyuncs.com`；检查 `.env` |
| 狗说话没声音 | voice 服务不可用 / 音量 0 | 看 `--check` 的音量输出 |

## 附录 C：换网络 / 长时间运行

- **换网络**（比如以后 PC2 接了 WiFi）：不用改代码。brain 用 `--host <PC2 新地址>`，或在 `brain/config.py` 的 `NETWORKS` 加一项后用 `--net <名字>`；
  部署用 `PC2=unitree@<新地址> tools/deploy_pc2.sh`。共享网络建议两端设置同一个 `A2_TOKEN`（见 README）。
- **长时间运行**：服务器没有 tmux，可以用 `screen -S brain` / `screen -r brain`；PC2 上两者都没有，保持 SSH 终端不断开。
