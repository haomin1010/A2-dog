# 阶段 1 测试运行手册（Runbook）

目标：在真机上验证"语音/文字 → 大模型 → 站/趴/走/跑/转/停/说/等"，并标定参数。
按顺序做，**每一步通过再进下一步**。第 0~3 步不会让狗动；从第 5 步开始狗会真实运动。

---

## 0. 安全检查（每次上真机前）

- [ ] 场地：狗周围 **3 米内无人无障碍**，前方至少 5 米直线空地。**狗没有避障**（自带 SLAM 处于待命，见 system_notes §4），撞到东西不会自己停。
- [ ] 宇树遥控器开机、已连上狗、**拿在一个专人手里**，这个人只负责急停。
- [ ] 电量 > 30%（`/state` 里看不到电量，用遥控器或 App 看）。
- [ ] 首次测试用 `--max-speed 0.3`。
- [ ] 所有人知道急停方法（从快到慢）：

| 方法 | 效果 | 延迟 |
|---|---|---|
| 遥控器 | 宇树官方急停/接管 | 最快，最可靠 |
| 说"停 / 别动 / 站住" | 跳过大模型直接停 | 说完 + 识别约 1s |
| brain 终端输入 `/stop` 回车 | 停止运动，原地站着 | 即时 |
| brain 终端 `Ctrl-C` | 连接断开 → body 立即 StopMove | 即时 |
| 拔服务器↔狗的网线 | body 1 秒收不到心跳 → StopMove | ~1s |
| brain 终端 `/damp` | 电机阻尼，**狗会软倒**，最后手段 | 即时 |
| PC2 上 `Ctrl-C` 停 body | 退出前打断当前动作并 StopMove | 即时 |

## 1. 接线与组网

```
  你的电脑 ──SSH(跳板 jd_10002)──► 服务器 ──USB 千兆网卡──网线──► 狗的对外网口 ──► PC2 net1
                                     │                                         PC2 eth0 ──狗内网──► PC1
                                     └─ USB 麦克风（Newmine）
```

1. **麦克风**：USB 麦克风插服务器。
2. **网线**：服务器上的 USB 千兆网卡（ASIX AX88179，接口名 `enxec1ac314450f`）→ 网线 → 狗身上连 PC2 的千兆网口（PC2 侧是 `net1`，板载 Intel I219）。
   PC2 与 PC1 之间（`eth0`，123 网段）是狗内部连好的，不用管。
3. **服务器网卡 IP**：由 NetworkManager 连接 `unitree-a2` 自动配置（已开自动连接，插上即生效）。如果没生效：
   ```bash
   sudo nmcli con up unitree-a2
   ```
4. **检查**（服务器上）：
   ```bash
   ip -br addr show enxec1ac314450f     # 应看到 192.168.124.222/24 和 192.168.123.222/24
   ping -c 3 192.168.124.162            # PC2 要通
   ```
   PC2 上再确认能到运控：
   ```bash
   ssh unitree@192.168.124.162
   ping -c 3 192.168.123.161            # PC1 要通
   ```

> **换别的网络**（比如以后 PC2 接了 WiFi）：不用改代码。brain 用 `--host <PC2 新地址>`，或在 `brain/config.py` 的 `NETWORKS` 加一项后用 `--net <名字>`；
> 部署用 `PC2=unitree@<新地址> tools/deploy_pc2.sh`。共享网络建议两端设置同一个 `A2_TOKEN`（见 README）。

## 4. 真机只读自检（狗开机、趴着）

终端 A：
```bash
ssh unitree@192.168.124.162
cd ~/lhm/A2-dog
tools/run_body.sh --check
```
**只读**：调用 GetState、读 `rt/sportmodestate`、读音量，不发运动指令。预期：

| 输出 | 期望 | 不对时 |
|---|---|---|
| `GetState: {...'fsm_name': ...}` | 有字典，记录 fsm_name | 报 code≠0 / 超时：PC1 不通或 DDS 网卡不对（`--iface eth0`） |
| `rt/sportmodestate: {...}` | x/y/yaw/mode 有值，mode=1（STAND_DOWN）| `None`：话题名不对，记下来反馈 |
| `音量: (0, ...)` | 有返回 | 失败不影响运动测试，speak 会失败 |

**把这段输出贴给开发者**，确认无误再继续。

## 6. 测试用例（按顺序，每条等完成再下一条）

在终端 B 输入文字指令。每条记录：是否成功、实际表现、PC2 日志里的报错。

| # | 输入 | 期望 | 重点观察 / 记录 |
|---|---|---|---|
| 1 | `/state` | posture=lying，pose 有值 | – |

| 3 | `趴下` | 趴下，✓ 已趴下 | 趴下用时 |
| 4 | `站起来` | 同 2 | – |
| 5 | `往前走半米` | 前进约 0.5m，✓ 移动了 x 米（里程计） | **卷尺量实际距离**；结果里写的是"里程计"还是"按时间估算" |
| 6 | `往后退半米` | 后退约 0.5m | 实测距离 |
| 7 | `向左转九十度` | 左转约 90° | 实际角度（地上贴胶带对比） |

## 8. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| brain：`连不上 body 192.168.124.162:8765` | body 没启动 / 网络不通 | PC2 上看 body 是否在跑；`ping 192.168.124.162` |
| brain：`body 拒绝连接：口令错误` | 两端 `A2_TOKEN` 不一致 | 统一口令或都不设 |
| body 启动报 `GetState`/`StandUp 失败 code=3104` 之类 | PC1 未响应、运控模式不对、遥控器占用 | 记下 code；检查遥控器是否在别的模式；狗重启 |
| `Move 失败 code=...` | 狗还没进入可行走状态 | 记录；可能需要先 BalanceStand（代码已自动做，若仍失败反馈） |
| `里程计中断` | `rt/sportmodestate` 停发 | 反馈；可临时改为按时间估算 |
| `移动超时（只走了 x 米）` | 被挡住、速度达不到 | 检查场地；反馈实际速度 |
| 结果写"按时间估算" | 没收到里程计 | 距离会不准，反馈 |
| 一直"没听到说话" | 麦克风设备不对 / 太小声 | `arecord -l`，`--mic` 换设备 |
| `语音识别失败` / `大模型调用失败` | 外网或 key 问题 | `curl https://dashscope.aliyuncs.com`；检查 `.env` |
| 狗说话没声音 | voice 服务不可用 / 音量 0 | 看 `--check` 的音量输出 |
